基线练习

特殊字体会导致基线不同，通常通过统一 font-size / line-height / vertical-align 解决。

1. 字体度量差异对比

默认行内文本 (Noto/Arial) 等宽字体 楷体
你会看到不同字体即使相同字号，基线/高度可能不同。

2. 图标/文字同排

🛠 默认 inline-block 🛠 inline-flex + align-items:center 🛠 inline-flex + flex-end

明确设置 display 和 vertical-align 能避免基线错位。

3. 电商价格排版（￥ 1090.8）

￥ 1090.8 元
￥ 1090.8 元
￥ 1090.8 元

常用做法：让符号、整数、单位为随行元素，行高统一、上下居中。

4. 推荐修复方式

  • 设置统一 `font-size`、`line-height`（尽量使用数值，例如 1.2）
  • 对于图标/按钮使用 `display:inline-flex; align-items:center;`
  • 必要时 `vertical-align: middle | text-bottom | baseline` 显式指定对齐
  • 使用开发者工具观察基线镜像（line box）
